# Demo script (target: ~90 seconds)

Build toward this early; let it drive priorities.

1. Student searches a book, sees availability and shelf location
2. Student is guided to the shelf
3. Student borrows by tapping shelf tag then book, **while offline**
4. Phone reconnects; loan syncs and is verified
5. Librarian audits the shelf and the report catches a misplaced book
6. Student returns at a station; librarian confirms the pending return
