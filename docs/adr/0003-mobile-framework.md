# ADR-0003: Mobile framework

- **Status:** Proposed. Flutter (+ Drift/SQLite) is the current proposal; React Native is a close alternative.

## To decide
- Flutter vs React Native (consider owner's existing TypeScript experience vs wanting to learn Flutter)
- Android-first vs both platforms (iOS needs a Mac, a physical iPhone, a paid developer account)

## Required before locking
A one-day NFC spike in `tools/nfc-spike` reading a real tag on the target platform(s).
